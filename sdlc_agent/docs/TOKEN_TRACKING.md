# Token Usage Tracking

The SDLC Agent harness now captures and aggregates token usage from LLM API calls, providing detailed cost and usage analytics in the observability system.

## Overview

Token usage is tracked at three levels:

1. **Per-trace** — Individual API calls in `traces.jsonl`
2. **Per-stage** — Aggregated by pipeline stage in `metrics.json`
3. **Per-tool** — Aggregated by tool type in `metrics.json`

## Schema Changes

### traces.jsonl

Each trace now includes an optional `token_usage` field:

```json
{
  "trace_id": "trace-abc123",
  "span_id": "span-def456",
  "tool": "claude_complete",
  "stage": "plan",
  "status": "ok",
  "duration_ms": 2341,
  "token_usage": {
    "input_tokens": 1523,
    "output_tokens": 487,
    "cache_creation_tokens": 0,
    "cache_read_tokens": 1200,
    "total_tokens": 2010
  },
  "ts": "2026-06-17T10:30:45Z"
}
```

### metrics.json

Aggregated metrics include token totals:

```json
{
  "totals": {
    "total_tokens": 45678,
    "total_input_tokens": 32100,
    "total_output_tokens": 13578,
    "total_cache_creation_tokens": 2500,
    "total_cache_read_tokens": 18000
  },
  "by_stage": {
    "plan": {
      "total_tokens": 12000,
      "input_tokens": 8500,
      "output_tokens": 3500
    }
  },
  "by_tool": {
    "claude_complete": {
      "total_tokens": 8500,
      "input_tokens": 6000,
      "output_tokens": 2500
    }
  }
}
```

## Usage Patterns

### Pattern 1: Using the helper function (Recommended)

```python
from sdlc_agent import get_harness, record_llm_usage
from sdlc_agent.integrations import ClaudeClient

harness = get_harness()
claude = ClaudeClient()

with harness.tool_span("claude_analyze", input_data="Analyze requirements") as span:
    result = claude.complete_json(
        system="You are an analyst",
        user="Analyze this: ...",
    )
    
    # Helper automatically extracts usage
    if hasattr(claude, "last_token_usage"):
        record_llm_usage(span, claude.last_token_usage)
```

### Pattern 2: Manual tracking

```python
with harness.tool_span("claude_review", input_data="Review code") as span:
    result = claude.complete_json(
        system="You are a reviewer",
        user="Review: ...",
    )
    
    # Manually set token usage
    if hasattr(claude, "last_token_usage"):
        usage = claude.last_token_usage
        span.set_token_usage(
            input_tokens=usage["input_tokens"],
            output_tokens=usage["output_tokens"],
            cache_creation_tokens=usage.get("cache_creation_input_tokens", 0),
            cache_read_tokens=usage.get("cache_read_input_tokens", 0),
        )
```

### Pattern 3: Direct Anthropic SDK

```python
import anthropic

client = anthropic.Anthropic(api_key=...)

with harness.tool_span("anthropic_messages") as span:
    message = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        max_tokens=1024,
        messages=[...],
    )
    
    # Works directly with Anthropic response objects
    record_llm_usage(span, message)
```

## Supported Backends

The token tracking system supports:

1. **Anthropic Messages API** — Full usage including prompt caching
2. **Google Gemini** — Input/output tokens (cache not supported)
3. **Claude Code CLI** — Usage when available from response
4. **Copilot Bridge** — Usage when available from response

## Token Types

| Token Type | Description | Cost Impact |
|------------|-------------|-------------|
| `input_tokens` | Prompt tokens sent to the model | Standard rate |
| `output_tokens` | Tokens generated by the model | Output rate (typically higher) |
| `cache_creation_tokens` | Tokens written to prompt cache | Cache write rate |
| `cache_read_tokens` | Tokens read from prompt cache | Cache read rate (90% discount) |
| `total_tokens` | Sum of input + output + cache_creation | Overall usage |

## Cost Analysis

You can analyze costs using the aggregated metrics:

```python
from pathlib import Path
import json

# Load metrics
metrics_file = Path(".claude/observability/metrics.json")
metrics = json.load(metrics_file.open())

# Approximate costs (Claude 3.5 Sonnet pricing as of June 2026)
COST_PER_1M_INPUT = 3.00  # $3 per million input tokens
COST_PER_1M_OUTPUT = 15.00  # $15 per million output tokens
COST_PER_1M_CACHE_WRITE = 3.75  # $3.75 per million cache write tokens
COST_PER_1M_CACHE_READ = 0.30  # $0.30 per million cache read tokens

totals = metrics["totals"]
input_cost = (totals["total_input_tokens"] / 1_000_000) * COST_PER_1M_INPUT
output_cost = (totals["total_output_tokens"] / 1_000_000) * COST_PER_1M_OUTPUT
cache_write = (totals["total_cache_creation_tokens"] / 1_000_000) * COST_PER_1M_CACHE_WRITE
cache_read = (totals["total_cache_read_tokens"] / 1_000_000) * COST_PER_1M_CACHE_READ

total_cost = input_cost + output_cost + cache_write + cache_read

print(f"Estimated cost: ${total_cost:.4f}")
print(f"  Input: ${input_cost:.4f}")
print(f"  Output: ${output_cost:.4f}")
print(f"  Cache write: ${cache_write:.4f}")
print(f"  Cache read: ${cache_read:.4f}")
```

## Querying Token Usage

### Command-line queries

```bash
# Total tokens used
jq -s 'map(.token_usage.total_tokens // 0) | add' .claude/observability/traces.jsonl

# Average tokens per call
jq -s '[.[] | select(.token_usage)] | (map(.token_usage.total_tokens) | add) / length' .claude/observability/traces.jsonl

# Token usage by stage
jq -s 'group_by(.stage) | map({stage: .[0].stage, total: (map(.token_usage.total_tokens // 0) | add)})' .claude/observability/traces.jsonl

# Top 10 most expensive calls
jq -s 'sort_by(.token_usage.total_tokens // 0) | reverse | .[0:10] | .[] | {tool, stage, tokens: .token_usage.total_tokens}' .claude/observability/traces.jsonl
```

### Python queries

```python
import json
from pathlib import Path
from collections import defaultdict

traces = []
with open(".claude/observability/traces.jsonl") as f:
    for line in f:
        traces.append(json.loads(line))

# Total by stage
by_stage = defaultdict(int)
for t in traces:
    if t.get("token_usage") and t.get("stage"):
        by_stage[t["stage"]] += t["token_usage"]["total_tokens"]

for stage, total in sorted(by_stage.items(), key=lambda x: x[1], reverse=True):
    print(f"{stage}: {total:,} tokens")

# Cache hit rate
total_input = sum(t["token_usage"]["input_tokens"] for t in traces if t.get("token_usage"))
cache_reads = sum(t["token_usage"]["cache_read_tokens"] for t in traces if t.get("token_usage"))

if total_input > 0:
    cache_hit_rate = (cache_reads / (total_input + cache_reads)) * 100
    print(f"\nCache hit rate: {cache_hit_rate:.1f}%")
```

## Best Practices

1. **Always track tokens** — Wrap all LLM calls with `harness.tool_span()` and use `record_llm_usage()`
2. **Monitor cache efficiency** — High cache read ratios indicate good prompt engineering
3. **Set budgets** — Add checks to fail fast if token usage exceeds thresholds
4. **Analyze by stage** — Identify which pipeline stages consume the most tokens
5. **Review expensive calls** — Use traces.jsonl to find outliers and optimize prompts
